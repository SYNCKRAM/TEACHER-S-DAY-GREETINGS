# Teachers' Day Message Card — Sir Randy Bello

A creative, professional Teachers' Day greeting card made with HTML, CSS, and JavaScript.

## Features

- Interactive 3D-style folder opening animation
- Personalized greeting for Sir Randy Bello
- Teacher photo displayed inside the opened message
- Heartfelt appreciation letter
- Sparkling ambient animation
- Responsive design for desktop and mobile
- Replay animation button
- Optional audio upload/playback directly in the browser
- No backend or database required

## Project Files

- `index.html` — webpage structure and personalized message
- `style.css` — visual design, responsive layout, folder animation, and effects
- `script.js` — folder interaction, sparkles, replay, and audio controls
- `teacher-photo.jpg` — supplied teacher photo

## How to Run

1. Keep all four files in the same folder.
2. Double-click `index.html`, or open it with Chrome/Edge/Firefox.
3. Click the **OPEN ME** folder.
4. The personalized message and photo will appear.
5. To add music, click **Add / Play Audio** and select an audio file from your computer.

## How to Customize

### Change the teacher's name
Open `index.html` and replace `Sir Randy Bello` wherever it appears.

### Change the message
Edit the paragraphs inside:
`<div class="message"> ... </div>`

### Change colors
Open `style.css` and edit the variables near the top:
`--gold`, `--blue`, `--rose`, etc.

### Add permanent background music
For a local project, place an audio file in the project folder and change the JavaScript/audio setup as desired. The included version intentionally lets the user choose an audio file so no copyrighted music is bundled with the project.
